# Veld (Migomojo Type House)

Licensed font purchased by TrailsTV. Web files from the Veld package's `Web-PS` folder (Regular 400, Bold 700, Black 900).
Self-hosted via `next/font/local` in `src/app/layout.tsx`: served from your own domain, preloaded, no third-party font service.
Distressed variants (Veld-BlackDistressed / Veld-BoldDistressed) are available in the original package if wanted later.
Keep this folder out of any public/open-source repo; the font license is yours, not redistributable.
