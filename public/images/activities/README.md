# Activity hero images (optional)

Name by activity slug: hiking.jpg, kayaking.jpg, skiing.jpg … and all.jpg for the Activities page.
If an activity has no image, the first park offering it that has one is used.

Quick start: `npm run images:activities` downloads the picks listed in
content/activity-images.json (NPS public-domain + Unsplash), resizes them to 2400px
and writes credits.json. Add or swap entries there — NPGallery or Unsplash page links work.
